\section{Introduction}
%==============================================================================

This document collects a set of nonlinear systems specifically designed to test Newton-type methods.

The proposed systems exhibit several difficult numerical behaviors:

\begin{itemize}
  \item singular or nearly singular Jacobians;
  \item poor scaling;
  \item strong nonlinear coupling;
  \item narrow valleys;
  \item oscillatory behavior;
  \item multiple roots;
  \item sensitivity to initial guesses.
\end{itemize}

For each problem we provide:
\begin{itemize}
  \item system definition;
  \item dimension;
  \item known solution;
  \item suggested initial guess;
  \item numerical difficulties.
\end{itemize}

%==============================================================================
\section{Powell Singular Function}
%==============================================================================

\subsection*{Dimension}

\[
n=4
\]

\subsection*{System}

\[
F(x)=
\begin{bmatrix}
x_1+10x_2 \\
\sqrt5(x_3-x_4) \\
(x_2-2x_3)^2 \\
\sqrt{10}(x_1-x_4)^2
\end{bmatrix}
\]

\subsection*{Solution}

\[
x^*=(0,0,0,0)
\]

\subsection*{Suggested Initial Guess}

\[
x^{(0)}=(3,-1,0,1)
\]

\subsection*{Difficulties}

\begin{itemize}
  \item singular Jacobian at the solution;
  \item only linear convergence near the root;
  \item strong nonlinear degeneracy.
\end{itemize}

\section{Brown Almost Linear Function}
%==============================================================================

\subsection*{Dimension}

\[
n=5
\]

\subsection*{System}

For:

\[
i=1,\dots,4
\]

\[
F_i(x)=x_i+\sum_{j=1}^5 x_j -6
\]

and:

\[
F_5(x)=\prod_{j=1}^5 x_j -1
\]

\subsection*{Solution}

\[
x^*=(1,1,1,1,1)
\]

\subsection*{Suggested Initial Guess}

\[
x^{(0)}=(0.5,0.5,0.5,0.5,0.5)
\]

\subsection*{Difficulties}

\begin{itemize}
  \item nearly rank-deficient Jacobian;
  \item global coupling;
  \item sensitivity to perturbations.
\end{itemize}

\section{Broyden Tridiagonal Function}
%==============================================================================

\subsection*{Dimension}

\[
n=10
\]

\subsection*{System}

\[
F_i(x)=
(3-2x_i)x_i
-x_{i-1}
-2x_{i+1}
+1
\]

with boundary conditions:

\[
x_0=x_{11}=0
\]

\subsection*{Suggested Initial Guess}

\[
x^{(0)}=(-1,\dots,-1)
\]

\subsection*{Difficulties}

\begin{itemize}
  \item sparse nonsymmetric Jacobian;
  \item poor scaling;
  \item nontrivial sparsity structure.
\end{itemize}

\section{Helical Valley Function}
%==============================================================================

\subsection*{Dimension}

\[
n=3
\]

\subsection*{System}

Define:

\[
\theta(x)=
\frac{1}{2\pi}
\arctan\left(\frac{x_2}{x_1}\right)
\]

Then:

\[
F_1=10(x_3-10\theta(x))
\]

\[
F_2=10(\sqrt{x_1^2+x_2^2}-1)
\]

\[
F_3=x_3
\]

\subsection*{Solution}

\[
x^*=(1,0,0)
\]

\subsection*{Suggested Initial Guess}

\[
x^{(0)}=(-1,0,0)
\]

\subsection*{Difficulties}

\begin{itemize}
  \item non smooth angular behavior;
  \item complicated basin of attraction;
  \item nearly singular Jacobian.
\end{itemize}

\section{Conclusions}
%==============================================================================

The proposed test set contains several difficult nonlinear systems useful for benchmarking:

\begin{itemize}
  \item Newton methods;
  \item damped Newton methods;
  \item trust-region methods;
  \item sparse linear solvers;
  \item automatic differentiation tools;
  \item globalization techniques.
\end{itemize}

The problems exhibit a wide range of numerical difficulties:
\begin{itemize}
  \item singular Jacobians;
  \item poor scaling;
  \item nonlinear degeneracy;
  \item oscillatory behavior;
  \item sparse structures;
  \item multiple solutions.
\end{itemize}
